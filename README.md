## 📌 Overview

**NIRAKSHAN** is an antivirus and proactive defense shield for women's digital safety. While conventional safety applications focus solely on reactive physical sirens and street-level panic buttons, NIRAKSHAN protects women against the fastest growing vector of modern gender-based violence: **AI-generated deepfakes, rogue Bluetooth tracking tags, and digital harassment/extortion.**

All threat analysis runs **100% locally on-device** in client memory with zero-cloud data storage, ensuring absolute privacy sovereignty.

---

## 🚀 Key Features

### 1. 🖼️ Deepfake Image Shield (Invisible Steganography)
- **Discrete Wavelet Transform (DWT) LSB Watermarking**: Injects an imperceptible cryptographic identity key and timestamp into personal photos before public posting.
- **Forensic Ownership Extraction**: Instantly extract verified cryptographic signatures from tampered or nudified images to prove authentic authorship.
- **Rogue Domain Sentinel**: Proactive browser warning extension filtering visits to known AI nudify and face-swap websites.

### 2. 📡 BLE Tracker Radar Scanner
- **Bluetooth Low Energy (BLE) Beacon Sweep**: Scans 2.4GHz frequencies for unknown tracking tags (Apple AirTag, Samsung SmartTag, Tile, and generic beacons).
- **Time & Spatial Correlation Algorithm**: Correlates RSSI signal strength and GPS hops to flag persistent stalkers traveling with you across multiple locations.
- **Force-Chime Acoustic Alarm**: Synthesizes locator alarm signals to pinpoint hidden hardware tags in bags, cars, or clothing.

### 3. 💬 Safe Chat Threat Auditor
- **Neural Threat Pattern Classifier**: Evaluates pasted messages, DMs, or emails for coercive gaslighting, financial blackmail, sextortion, and physical stalking cues.
- **Dynamic Speedometer Risk Index**: Classifies risk into **Low / Medium / Critical High** with itemized legal and psychological reasoning.
- **Police Dossier Generator**: 1-click export of structured evidence dossiers formatted for **Cyber Crime Helpline (1930)** and **cybercrime.gov.in** under IT Act Sections 66E, 67A, and IPC 506.

## 🛠️ Tech Stack

- **Core & UI**: HTML5, Modern CSS (Custom Properties, Glassmorphism, Responsive Grid), Vanilla JavaScript (ES6+).
- **Steganography Engine**: Discrete Wavelet Transform (DWT) & Least Significant Bit (LSB) Canvas Pixel Processor.
- **BLE Hardware Telemetry**: Bleak API & HTML5 2D Canvas Sonar Radar.
- **Audio Synthesis**: Web Audio API Oscillator for hardware alarm acoustic localization.
- **Backend & Extensions**: Python 3.11+ Daemon, Chrome Extension Manifest V3.

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/nileshkumar-3/NIRAKSHAN.git
cd NIRAKSHAN
```

### 2. Run locally
You can open `index.html` directly in your browser, or spin up a local server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js / npx
npx serve .
```

Open your browser at: **`http://localhost:3000`**
